# Licences et propriété intellectuelle — Observatoire Mondial

## Objet

Ce dossier organise la documentation relative aux droits d'auteur,
aux licences, aux autorisations et aux ressources externes utilisées
dans le projet.

## Documents

- `INVENTAIRE-DES-LICENCES.md` : recensement des licences applicables.
- `PROPRIETE-INTELLECTUELLE.md` : principes de protection des créations.
- `REGISTRE-DES-RESSOURCES-TIERCES.md` : inventaire des ressources externes.
- `AUTORISATIONS-DE-REUTILISATION.md` : règles de réutilisation des contenus.

## Principes

Chaque ressource doit être associée à une provenance et à des conditions
de réutilisation suffisamment claires.

Une licence applicable au code ne s'étend pas automatiquement aux textes,
images, vidéos, logos, marques ou autres créations.

## Preuves

Conserver, lorsque cela est pertinent :

- les fichiers sources ;
- les versions datées ;
- les licences originales ;
- les autorisations écrites ;
- les contrats ;
- les crédits requis ;
- les références des ressources utilisées.

## Prudence juridique

Ce dossier constitue une documentation interne de gestion des droits.
Il ne remplace pas une analyse juridique adaptée à une situation précise.

Aucun droit exclusif, dépôt de marque ou enregistrement juridique
ne doit être annoncé comme acquis sans confirmation.
