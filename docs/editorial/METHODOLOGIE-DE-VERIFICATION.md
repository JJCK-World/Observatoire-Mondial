# Méthodologie de vérification — Observatoire Mondial

## 1. Objet

Cette procédure définit les contrôles à effectuer avant la publication
d'un article, d'une analyse, d'une vidéo ou d'un contenu social.

## 2. Étape 1 — Définir les affirmations

Identifier les affirmations essentielles du contenu :

- qui est concerné ;
- ce qui s'est produit ;
- où et quand ;
- quelles données sont avancées ;
- quelles décisions sont attribuées ;
- quelles conséquences sont présentées ;
- quelles interprétations sont proposées.

Les affirmations vérifiables doivent être séparées des opinions.

## 3. Étape 2 — Identifier les sources

Pour chaque affirmation importante, rechercher la source la plus directe
et la plus pertinente.

Privilégier les documents originaux, les données officielles, les études
scientifiques ou les déclarations directement attribuables lorsque
cela correspond au sujet.

## 4. Étape 3 — Contrôler les détails

Vérifier notamment :

- l'orthographe des noms et organismes ;
- les dates et lieux ;
- les unités et calculs ;
- les citations ;
- les liens ;
- les versions de produits et logiciels ;
- les résultats sportifs ;
- les chiffres et leur période de référence ;
- le contexte des déclarations.

Toute conversion ou tout calcul doit être reproductible.

## 5. Étape 4 — Recouper

Chercher des confirmations indépendantes lorsque le sujet, les risques
ou l'incertitude le justifient.

Vérifier que plusieurs sources ne reprennent pas simplement la même
information initiale sans contrôle supplémentaire.

## 6. Étape 5 — Évaluer les incertitudes

Classer les éléments selon leur état réel :

- confirmé par des preuves suffisantes ;
- déclaration attribuée ;
- interprétation ou analyse ;
- hypothèse ;
- non confirmé.

Ne pas transformer une possibilité en certitude.

## 7. Étape 6 — Vérifier les médias

Pour les images et vidéos, examiner leur origine, leur date, leur contexte,
les modifications éventuelles, les crédits et les droits de réutilisation.

Si l'authenticité d'un média ne peut pas être établie, ne pas le présenter
comme une preuve certaine d'un événement réel.

## 8. Étape 7 — Contrôle final

Avant publication, contrôler :

- la cohérence du titre avec le contenu ;
- l'exactitude des informations essentielles ;
- les attributions et liens ;
- les incertitudes signalées ;
- l'absence de citation inventée ;
- les crédits et autorisations ;
- les éventuelles données personnelles ;
- les risques de diffamation ou d'atteinte aux droits ;
- le fonctionnement des liens.

## 9. Étape 8 — Documenter

Pour les publications importantes, conserver un relevé daté des sources
principales, des contrôles effectués et des limites restantes.

Une case cochée ou une note de validation ne constitue une preuve que
si le contrôle correspondant a réellement été effectué.

## 10. Blocage de publication

Suspendre la publication lorsque :

- un fait central reste insuffisamment vérifié ;
- une source essentielle est introuvable ou contredite ;
- une citation ne peut pas être authentifiée ;
- un média risque d'induire le public en erreur ;
- les droits de réutilisation sont inconnus et indispensables ;
- un risque sérieux ne peut pas être maîtrisé.

Le contenu peut être repris après vérification ou reformulation.

## 11. Note méthodologique

Selon la nature du sujet, ajouter une note précisant les principales
sources consultées, la date de vérification et les limites identifiées.

Formulation possible :

« Les informations ont été examinées à partir des sources publiques
identifiées à la date de vérification. Certaines données peuvent évoluer.
Nous ne pouvons prétendre qu'il est exempt de toute erreur. »

Cette formulation doit être adaptée au contenu et ne doit pas servir
à justifier des vérifications insuffisantes.
