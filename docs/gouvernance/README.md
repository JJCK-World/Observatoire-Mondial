# Gouvernance — Observatoire Mondial

## Objet

Ce dossier définit les responsabilités, les autorisations et les
principes de décision applicables au projet Observatoire Mondial.

## Documents

- `ORGANISATION-DU-PROJET.md` : périmètre et organisation du projet.
- `RESPONSABILITES-ET-AUTORISATIONS.md` : droits de décision et limites.
- `GESTION-DES-COLLABORATIONS.md` : règles applicables aux collaborations.
- `HISTORIQUE-DES-DECISIONS.md` : traçabilité des décisions importantes.

## Responsable

JJCK est le fondateur et responsable du projet Observatoire Mondial.

Les décisions structurantes doivent respecter le cahier des charges maître,
les droits applicables et les autorisations nécessaires.

## Principe de séparation

Les projets numériques distincts ne doivent pas être fusionnés, transférés
ou interconnectés sans autorisation explicite.

## Traçabilité

Les décisions importantes doivent préciser leur date, leur objet,
leur justification, leur responsable et leur état de réalisation.

Un projet décidé n'est pas nécessairement un projet exécuté.
