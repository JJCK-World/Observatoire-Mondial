# Inventaire des licences — Observatoire Mondial

## 1. Objectif

Recenser les licences et conditions d'utilisation applicables aux
fichiers, logiciels, médias et autres ressources du projet.

## 2. Éléments à inventorier

Examiner notamment :

- le code source ;
- les bibliothèques et dépendances ;
- les polices de caractères ;
- les icônes ;
- les images ;
- les vidéos ;
- les musiques et effets sonores ;
- les logos et éléments graphiques ;
- les articles et textes ;
- les modèles et documents ;
- les données externes ;
- les outils de production.

## 3. Documents de licence à vérifier

Les documents identifiés dans l'historique du projet comprennent :

- `LICENSE`
- `COPYRIGHT.md`
- `EDITORIAL-LICENSE.md`
- `LICENCE-PROPRIETAIRE-OBSERVATOIRE-MONDIAL.md`
- `THIRD-PARTY-LICENSES.md`

Leur présence, leur contenu, leur portée et leur état actuel doivent
être vérifiés dans le dépôt avant toute conclusion.

Cette liste ne confirme pas que tous ces fichiers sont actuellement
présents, complets ou cohérents entre eux.

## 4. Informations à conserver

Pour chaque licence ou autorisation, enregistrer si possible :

- le nom de la ressource ;
- son auteur ou titulaire ;
- sa provenance ;
- sa version ;
- le texte de licence applicable ;
- les usages autorisés ;
- les restrictions ;
- les obligations d'attribution ;
- les obligations de redistribution ;
- les dates pertinentes ;
- les preuves conservées.

## 5. Code et contenus éditoriaux

Ne pas supposer qu'une licence de code couvre les articles, images,
vidéos, logos ou marques du projet.

La portée d'une licence doit être déterminée à partir de son texte,
de son périmètre et des droits effectivement détenus.

## 6. Dépendances logicielles

Pour chaque dépendance intégrée, identifier sa version et sa licence.

Vérifier les obligations de conservation des notices, d'attribution,
de redistribution ou de mise à disposition du code lorsqu'elles existent.

Ne pas présenter une dépendance comme libre de toute restriction sans
avoir vérifié les conditions applicables.

## 7. Ressources multimédias

Pour chaque image, vidéo, musique ou autre média externe, vérifier
les droits de reproduction, d'adaptation, de diffusion et d'utilisation
commerciale, selon le besoin réel.

Une ressource accessible gratuitement sur Internet n'est pas
automatiquement libre de droits.

## 8. Ressources sans statut clair

Si la licence ou l'autorisation est inconnue :

- rechercher la source originale ;
- examiner les conditions officielles ;
- contacter le titulaire si nécessaire ;
- remplacer la ressource si les droits ne peuvent pas être établis.

Ne pas considérer l'absence de mention d'interdiction comme une autorisation.

## 9. Révision

Mettre à jour cet inventaire lors de l'ajout ou du remplacement d'une
dépendance ou d'un média, et lorsque les conditions d'utilisation changent.

## 10. Limites

Cet inventaire ne constitue pas à lui seul une certification juridique.
Les situations complexes ou les usages commerciaux à risque doivent
faire l'objet d'un examen adapté.
