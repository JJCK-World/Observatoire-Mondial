# Procédure de correction — Observatoire Mondial

## 1. Objectif

Garantir le traitement traçable et proportionné des erreurs, des mises
à jour et des demandes de rectification concernant les publications.

## 2. Réception d'un signalement

Un signalement peut provenir d'un lecteur, d'un auteur, d'un organisme
concerné ou d'un contrôle interne.

Enregistrer, lorsque les informations sont disponibles :

- l'article concerné ;
- le passage signalé ;
- la nature de l'erreur alléguée ;
- les éléments justificatifs ;
- la date de réception ;
- l'état du traitement.

Ne pas publier inutilement les données personnelles du signalant.

## 3. Qualification

Distinguer notamment :

- erreur factuelle ;
- erreur de date, de nom ou de chiffre ;
- citation inexacte ;
- lien cassé ;
- information devenue obsolète ;
- contexte incomplet ;
- désaccord d'interprétation ;
- demande liée aux droits ou à la vie privée.

Un désaccord d'opinion n'est pas automatiquement une erreur factuelle.

## 4. Vérification

Examiner le signalement à partir des sources pertinentes.

Comparer le contenu publié avec les éléments disponibles. Si nécessaire,
rechercher une confirmation indépendante ou solliciter des précisions.

Ne pas rejeter un signalement uniquement parce qu'il remet en cause
une publication antérieure.

## 5. Décision

Selon les résultats :

- corriger l'erreur confirmée ;
- compléter le contexte ;
- ajouter une mise à jour datée ;
- signaler que l'information demeure incertaine ;
- maintenir le contenu si les éléments ne démontrent pas l'erreur ;
- retirer ou suspendre temporairement le contenu lorsqu'un risque sérieux
  le justifie.

Toute décision doit être proportionnée aux faits établis.

## 6. Correction publique

Pour une erreur significative, indiquer clairement ce qui a été corrigé
et, lorsque cela est utile, à quelle date.

Ne pas effacer silencieusement une erreur importante si cela empêche
le lecteur de comprendre la modification.

Les corrections mineures de typographie peuvent être effectuées sans
note publique si elles ne modifient pas le sens.

## 7. Réseaux sociaux

Si une erreur importante a été diffusée sur Facebook ou TikTok, examiner
les possibilités de correction sur la plateforme concernée.

Selon les fonctionnalités disponibles, publier une rectification,
modifier la légende, ajouter un commentaire ou retirer le contenu si
la situation l'exige.

Une correction sur le site ne garantit pas que les copies partagées
ailleurs soient corrigées automatiquement.

## 8. Conservation de l'historique

Pour chaque correction significative, conserver :

- la date ;
- le contenu concerné ;
- l'erreur constatée ;
- les éléments de vérification ;
- la modification réalisée ;
- la justification de la décision.

Ne pas conserver des données personnelles inutiles.

## 9. Délais et suivi

Traiter les signalements dans un délai raisonnable selon leur gravité,
leur complexité et les risques éventuels.

Les risques graves pour les personnes, les erreurs centrales et les
questions juridiques nécessitent une priorité adaptée.

Aucun délai précis ne doit être annoncé s'il ne peut pas être respecté.

## 10. Clôture

Le signalement peut être clôturé lorsque la vérification et la décision
sont documentées et que les actions nécessaires ont été effectuées.

La clôture ne doit pas être déclarée avant la réalisation des actions
annoncées.
