# Politique des sources — Observatoire Mondial

## 1. Objectif

Cette politique définit comment rechercher, sélectionner, citer et
conserver les sources utilisées dans les articles et les productions
multimédias d'Observatoire Mondial.

## 2. Ordre de préférence

Le type de source doit être adapté à l'affirmation à vérifier.

Privilégier, lorsque cela est pertinent :

1. les documents originaux et les données primaires ;
2. les textes et publications des institutions compétentes ;
3. les études scientifiques originales et leurs données associées ;
4. les déclarations directement attribuables à leurs auteurs ;
5. les médias reconnus disposant de méthodes éditoriales identifiables ;
6. les sources spécialisées capables de démontrer leur expertise.

Cette liste constitue une orientation et non une garantie automatique
de fiabilité.

## 3. Évaluation d'une source

Pour chaque source importante, examiner :

- l'identité de l'auteur ou de l'organisme ;
- sa compétence sur le sujet ;
- la date de publication et de mise à jour ;
- la méthode utilisée ;
- les documents ou données à l'appui ;
- les intérêts susceptibles d'influencer son contenu ;
- la possibilité de vérifier l'information indépendamment ;
- les limites et corrections éventuelles.

Une source anonyme, non datée ou difficile à authentifier nécessite
une prudence particulière.

## 4. Recoupement

Les affirmations importantes doivent être recoupées lorsque cela est
possible et proportionné au sujet.

Plusieurs sites reprenant un même communiqué ne constituent pas
nécessairement plusieurs confirmations indépendantes.

Il faut identifier, lorsque possible, la source d'origine de l'information.

## 5. Attribution

Les sources doivent être liées ou citées à proximité des affirmations
qu'elles soutiennent.

Les formulations doivent préciser l'origine de l'information, par exemple :

- « Selon le communiqué publié par... »
- « D'après les données de... »
- « Dans son étude publiée le... »
- « L'organisme indique que... »

Ne pas utiliser une formulation qui attribue une information à une source
si cette source ne la contient pas réellement.

## 6. Citations et traductions

Toute citation doit être fidèle à la source.

Les coupures ne doivent pas altérer le sens. Les ajouts explicatifs doivent
être identifiables. Les traductions doivent préserver le contenu original.

Les citations longues et les reproductions substantielles doivent respecter
les règles de droit d'auteur applicables.

## 7. Dates et données évolutives

Pour les chiffres, prix, calendriers, classements, résultats et informations
susceptibles de changer, conserver la date ou la période de référence.

Ne pas présenter une ancienne donnée comme actuelle sans vérification.

## 8. Sources contradictoires

Lorsque des sources crédibles divergent :

- identifier précisément le point de désaccord ;
- vérifier leurs dates, méthodes et périmètres ;
- rechercher les documents primaires disponibles ;
- exposer les différences importantes ;
- signaler ce qui ne peut pas être tranché.

Ne pas choisir une source uniquement parce qu'elle confirme une conclusion
déjà souhaitée.

## 9. Réseaux sociaux et contenus utilisateurs

Une publication sur un réseau social ne constitue pas, à elle seule,
une preuve suffisante de la véracité d'une affirmation.

Vérifier le compte, la date, le contexte et l'authenticité du contenu
lorsque ces éléments sont déterminants.

Une image ou une vidéo doit être examinée pour détecter les reprises
anciennes, les montages et les changements de contexte.

## 10. Sources inaccessibles

Si une source ne peut plus être consultée, rechercher une copie officielle,
une archive autorisée ou une autre source fiable.

Ne pas prétendre avoir consulté un document dont le contenu n'a pas été
accessible et vérifié.

## 11. Registre de sources

Pour les dossiers importants, conserver si possible :

- le titre de la source ;
- l'auteur ou l'organisme ;
- l'URL ;
- la date de publication ;
- la date de consultation ;
- l'affirmation soutenue ;
- les limites identifiées ;
- la version ou la copie de référence, lorsque sa conservation est licite.

## 12. Règle de publication

Une source ne doit jamais être inventée, et une référence ne doit pas
être ajoutée uniquement pour donner une apparence de crédibilité.

Si une affirmation importante ne peut pas être suffisamment étayée,
elle doit être reformulée, explicitement qualifiée ou écartée.
