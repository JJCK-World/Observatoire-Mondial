# Propriété intellectuelle — Observatoire Mondial

## 1. Objectif

Définir les principes de documentation et de protection des créations
associées à Observatoire Mondial, sans revendiquer des droits qui
n'auraient pas été établis.

## 2. Créations concernées

Selon les éléments effectivement produits, l'inventaire peut comprendre :

- les articles et textes originaux ;
- les logos et variantes ;
- les identités graphiques ;
- les illustrations originales ;
- les photographies ;
- les vidéos et montages ;
- les scripts et programmes ;
- les documents éditoriaux ;
- les modèles de publication ;
- les créations multimédias ;
- les éléments originaux diffusés sur les réseaux sociaux.

## 3. Identification de l'auteur et des titulaires

Pour chaque création importante, identifier son auteur, la date connue,
les éventuels coauteurs et le titulaire des droits lorsque celui-ci
peut être établi.

Le fait qu'une création soit publiée sur le site ne suffit pas à
démontrer que tous les droits correspondants appartiennent au projet.

Les contributions de tiers doivent être examinées selon les accords
et les règles applicables.

## 4. Preuves de création

Conserver, lorsque cela est pertinent :

- les fichiers sources ;
- les versions intermédiaires ;
- les dates de création et de modification ;
- les commits Git ;
- les échanges d'autorisation ;
- les contrats ;
- les factures pertinentes ;
- les licences ;
- les empreintes SHA-256 des fichiers importants.

Une empreinte permet de vérifier qu'un fichier correspond à une version
donnée ; elle ne prouve pas, à elle seule, la titularité des droits.

## 5. Code source

Les droits applicables au code doivent être déterminés à partir
des fichiers de licence et des conditions des dépendances.

Une licence accordée sur le code ne s'étend pas automatiquement
aux autres catégories de contenus.

## 6. Articles et contenus éditoriaux

Les articles originaux doivent être distingués des citations,
documents publics, extraits tiers et autres éléments externes.

Les droits sur une œuvre et les règles particulières applicables
aux documents publics peuvent varier selon la juridiction et le type
de contenu.

Toute réutilisation doit être examinée selon son contexte réel.

## 7. Logos, marques et identité visuelle

Conserver les fichiers sources, les versions datées et les éléments
permettant d'identifier l'origine des créations graphiques.

Ne pas confondre la création d'un logo, son usage, l'acquisition
de droits d'auteur et l'enregistrement éventuel d'une marque.

Ne pas affirmer qu'une marque est enregistrée ou protégée par un dépôt
sans preuve correspondante.

## 8. Créations réalisées avec des outils d'IA

Pour les créations produites avec des outils d'intelligence artificielle,
conserver si possible les instructions de création, les fichiers sources,
les versions et les conditions du service utilisé.

Examiner les conditions contractuelles du service ainsi que les droits
des éléments intégrés.

Ne pas garantir une exclusivité ou une protection juridique absolue
sans analyse adaptée.

## 9. Utilisation par des tiers

Toute autorisation de réutilisation doit préciser, lorsque nécessaire,
les contenus concernés, les usages autorisés, les conditions de crédit,
la durée, le territoire et les restrictions.

L'autorisation de partager un lien ne signifie pas nécessairement
l'autorisation de reproduire l'œuvre.

## 10. Réaction à une utilisation contestée

En cas d'utilisation non autorisée présumée :

1. identifier précisément le contenu ;
2. conserver les éléments de preuve disponibles ;
3. vérifier les droits et les autorisations ;
4. documenter les faits ;
5. examiner les moyens de contact ou de recours appropriés.

Ne pas publier d'accusation sans éléments suffisants.

## 11. Révision

Mettre à jour l'inventaire lorsque des créations sont ajoutées,
remplacées, licenciées ou transférées.

Les questions juridiques complexes doivent être examinées avec
un professionnel compétent lorsque cela est nécessaire.
